# F101 모델 선정 근거

2026-10-21 작성. 비교 기준은 명세서의 정확도·속도·메모리·라이선스다.
YOLO11n을 기준으로 같은 계열의 YOLO11s와 비교했다.

| 기준 | YOLO11n | YOLO11s |
|---|---:|---:|
| 공개 COCO val mAP50–95 | 39.5 | 47.0 |
| 공개 CPU ONNX 지연(ms) | 56.1 ± 0.8 | 90.0 ± 1.2 |
| 파라미터 수(M) | 2.6 | 9.4 |
| FP32 파라미터만의 계산상 메모리(MiB) | 약 9.9 | 약 35.9 |
| 라이선스 선택지 | AGPL-3.0 / Enterprise | 동일 |

정확도·속도·파라미터는 [Ultralytics YOLO11 공식 성능표](https://docs.ultralytics.com/models/yolo11/)의
공개 값이다. 라이선스 선택지는 [공급자 라이선스 안내](https://www.ultralytics.com/license)를 참고했다.
실제 배포 형태에 적용되는 조건은 별도로 확인해야 하며 교육자료의 공개 허용을 뜻하지 않는다.

메모리 값은 `파라미터 수 × 4바이트 / 2^20`으로 계산한 FP32 파라미터 저장 공간의 추정이다.
activation·프레임워크·입력·버퍼는 포함하지 않아 프로세스 RSS와 동일하지 않다.
YOLO11s는 이번 환경에 로드하지 않았고 s의 실행 메모리를 측정했다고 주장하지 않는다.

YOLO11s가 공개 정확도는 높지만 YOLO11n은 작은 파라미터 규모와 더 낮은 공개 CPU 지연을
가지며 명세서가 지정한 모델이다. 우선 CPU에서 재현 가능한 기준선을 만들기 위해 n을 선택했다.
ONNX 공개 지연과 이번 PyTorch 실행 시간은 실행 엔진과 장비가 달라 직접 비교하지 않는다.
이번 샘플에는 평가용 정답 라벨이 없어 로컬 정확도/mAP는 측정하지 않았다.

실제 n 모델의 CPU 지연·RSS 결과는 `artifacts/measurement.csv`와
[검증 문서](f101_validation.md)에 기록했다.
